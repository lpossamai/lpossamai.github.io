AI Infrastructure Security Engineer

Securing the platform layer of an AI-native operating system built for large, regulated institutions: the cloud, Kubernetes, identity, and networking that AI agents run on.

It is a hands-on builder role. I write the code and ship the infrastructure alongside the platform, product, and ML teams, so secure-by-default is the paved road rather than a review at the end.

  • Zero Trust
  • Kubernetes
  • Service mesh
  • Terraform
  • Secrets & KMS

  1. Identity & isolation

    Secrets management, access control, and workload isolation across cloud and Kubernetes.

  2. Zero Trust

    Machine identity, short-lived credentials, least privilege, and encrypted service-to-service traffic.

  3. Agent workloads

    Secure execution environments and data-access paths for code and actions taken by AI agents.

  4. Forward-deployed

    Hardened, bespoke VPCs and customer-environment deployments, each with its own attack surface.

  5. Guardrails as code

    Security built into Terraform and deployment workflows so it scales with the platform.

  6. Threat modeling

    Trust boundaries and failure modes across every infrastructure layer, turned into concrete controls.
